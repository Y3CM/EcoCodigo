Historias de usuarios 

Historia de Usuario 


HU01 

Como usuario de la plataforma, quiero activar un modo oscuro, para poder navegar de forma más cómoda en entornos con poca luz. 


Descripción  
Debe existir un botón o interruptor para activar/desactivar el modo oscuro. 


  Criterio de aceptación 

El modo oscuro debe aplicarse a toda la interfaz (textos, fondos, botones). 

  

HU02 

Como usuario, quiero poder visualizar video sin salir de la plataforma. 

Descripción  

El video debe mostrarse incrustado (embebido) dentro de la página. 

  

Si el enlace no es válido, el sistema debe mostrar un mensaje de error. 

HU03 

 Como usuario, quiero diferentes imágenes dentro de la plataforma, para mejorar la interacción 
 
Descripción  

Mostrar variedades de imágenes para interactuar  

HU04 

Como usuario, quiero registrarme e iniciar sesión en la plataforma, para poder acceder a funciones personalizadas y guardar mi progreso. 

Descripción  

Debe permitir registro con correo y contraseña. 

Debe permitir iniciar sesión con las credenciales registradas. 

Manejo de errores (usuario no encontrado, contraseña incorrecta). 

 

HU05 

Como usuario, quiero ver animaciones en botones y elementos de la interfaz, para tener una experiencia más dinámica y agradable. 

Descripción  

Animaciones suaves al pasar el mouse o hacer clic. 

Transiciones visibles en elementos interactivos. 

Animaciones no deben afectar el rendimiento.
